## 1. 单图检测推理会覆盖标注（已修）

### 改之前

```python
boxes = dt.predict(self.canvas.current_image_path)
if boxes:
    self._box_manager.delete_all()          # ← 里面直接 save()
    for b in boxes:
        self._box_manager.add_box(...)      # ← 每个框一次 save()
```

`BoxManager.save()` 写的是 `images/<base>_det.json`，也就是**标注的权威文件**；
而批量推理写的是 `outputs/`。两条路口径不一致。

两个后果：

1. **人的 10 个 GT 框在第一次 `save()` 时就落盘没了。** 撤销栈救不回来 ——
   `undo()` 只是把内存里的旧列表写回去，前提是文件没被覆盖过。
2. 用户的心理是"我标完了，跑一下模型看看效果"，不会预期标注被换成预测，
   而且**没有任何确认框**。

附带问题：6 个框 = 6 次写盘（`add_box` 每次 `save()`）。

### 改之后

```
predict() → 写 outputs/<base>_det.json（含 meta.infer_ms）
          → load_predictions() 读进**预测层**（BoxManager._pred_boxes）
          → 画布重绘
```

- 与批量同一口径：预测属于 `outputs/`，`images/<base>_det.json` 只在
  **用户手动改框**时写（`add_box` / `update_box` / `delete_box` / `undo`）。
- 类别按**出现顺序**收集，与 `DetWriter` 节点一致（`flow/nodes/output.py`）。
- 预测层只读，`pred_boxes` 不参与 `save()`。
- 落盘失败（例如 outputs 不可写）不挡"看得见预测"：退回
  `set_pred_boxes(boxes)` 只更新内存。
- 顺手把「结果 / 耗时」列刷了（`_pred_count` / `_infer_times` + 重算一次列表），
  与批量的刷新口径相同。

新增接口：`BoxManager.set_pred_boxes(boxes)`。

## 2. 坏标注文件先留档（已修）

### 风险是容错带进来的

`BoxManager.load()` 现在吞掉异常、按 0 个框显示。于是：

```
坏文件 → 打开显示 0 个框 → 用户随手加一个框 → save() → 原文件被 1 个框整体替换
```

哪怕原文只是被截断 2 个字节、还能手工救回 9 个框，也没了。
更糟的路径：显示 0 个框 → 用户心想"反正空的，跑个推理看看" → 一跑连 `.bad` 都来不及救
（这条现在被第 1 节堵住了）。

### 改法

`load()` 解析失败时先 `_quarantine(json_path)`：

```
images/a_det.json → images/a_det.json.bad-20261116T170500
                    （重名再加 -1、-2…）
```

- 原文**字节不变**，只改名。
- 改名失败（文件被别的进程占着）**不挡加载**，但要把 `留档失败: ...` 记进
  `load_errors["annot"]` —— 否则用户以为原文件还在、内容也还在，其实一编辑就被覆盖。
- 成功时错误信息追加 `；原文件已留档: a_det.json.bad-...`，界面日志那一行
  （`⚠️ 该图标注文件损坏，已按 0 个框显示：...`）会把路径一起打出来。
- `load_predictions()` 坏文件**不留档**：那是可以重跑出来的产物，留档只会堆垃圾。

### 语义变化（写测试时踩到）

以前"坏文件留在原地、再加载一次仍能读到错误原因"。现在第一次加载就改名了，
所以 `tests/test_corrupt_det_json.py` 里那条用例改成钉：不弹原始异常 +
工程不半开 + 原文进了 `.bad` + 日志提到"留档"。这也更贴近用户能感知的契约。

## 3. tooltip 判据改成看语义（P3）

```python
# 改前：看渲染出来的文字
if col == 4 and val == "0":
# 改后：看数据语义
if col == 4 and data.get('has_ann') and data.get('shape_count') == 0:
```

分类模式这一格是**类别名**（`", ".join(shape_labels)`），而字符分类工程的类别名
就叫 `"0"`、`"1"` —— 旧判据会给它挂上"空标注：0 个框"的提示，实际它有类别。

## 7. 影响面 / 没做

- **单图推理的结果不再写进 `images/`**：想把它变成标注要手动框（或在画布上"采纳预测"，
  目前没有这个按钮）。这是有意的：预测和标注必须分层。
- `outputs/<base>_det.json` 会被单图推理**覆盖**（它是产物，不是标注）。若同一张图
  之前跑过批量，重跑单图后那份会被更新 —— 语义正确，但要知道。
- 留档文件不会自动清理（`.bad-*` 会一直堆）。要清理得手动，或以后加"归档"入口。
