# 检测工程「导入图片 + 导入标注 → 直接训练」打通

日期：2026-11-16
涉及工程：`赢合_南昌赣锋_储能电池_明码字符OD_L1_587AH_连接片_Flow6701_Tao_20261112`

## 1. 现象

用户原话："我这个工程是导入图片和导入标注建成的，希望做完这两件事后就能设置参数开始训练，我们软件支持吗？"

答案当时是"不支持"：图片和 labelme JSON 都导进去了，画布检测模式也能看到框，
但点训练只会得到

```
ERROR: No detection annotations found
```

## 2. 根因（两条，缺一不可）

1. **训练只认 `_det.json`**：`detection/dataset.py: get_annotated_count()` 和
   `build_yolo_dataset()` 扫的是 `images/<base>_det.json`（COCO 子集），
   不是 labelme 的 `images/<base>.json`。
2. **界面导入只生成掩膜**：`_import_json_for_selected()` 复制完 JSON 之后，
   不分任务类型一律调 `_rebuild_masks_for_imported()` —— 产出
   `annotations/<base>_mask.png`（**语义分割**用的），一个 `_det.json` 都没有。

所以"导入成功"和"能训练"之间少了一步转换，而这步原来只有一个命令行工具
（`tools/labelme_rect_to_det.py`）能做，普通用户根本不知道要跑它。

## 4. 顺带修的两处（同一批，都是真实缺陷）

1. **`_open_project` 里 `internal` 可能未绑定**：原来映射表和读取都内联在
   `try` 里，工程缺 `project.json` / JSON 损坏时 `except: pass` 之后紧接着
   `internal in ("classification", ...)` 直接 `NameError`。
   `test_undefined_names` 查不出这种"可能未绑定"，因为它在函数内是**有赋值的**。
   现在统一走 `read_task_type()`，读不到按 `segmentation` 兜底。

2. **`import detection.dataset` 会顺带把 PyQt5 拉进来**：包 `__init__` 硬导入
   `box_overlay`。命令行工具、无显示环境、以及"PyQt5 先于 torch 导入"
   （交接说明地雷 #2，WinError 1114 c10.dll）都因此中招。现改为懒加载。

## 6. 关于"模型保存路径"那条旧结论：**是我说错了**

上一轮说"`detection/trainer.py:190` 把 `best.pt` 拷到了 `results_dir`，
不是 `models/detection/`"。实跑对不上，回去逐行看：

```python
results_dir = self.project_dir / "models" / "detection"   # trainer.py:149
...
project=str(results_dir), name="train"                     # → models/detection/train/
shutil.copy2(best_pt, results_dir / "best.pt")             # → models/detection/best.pt
```

写的就是 `models/detection/best.pt`，和 3 个消费方
（`_task_model_exists`、`predict()`、`flow/nodes/detection.py`）一致。
**没有改这段代码**——照错结论去改只会把对的改错。

## 7. 已知限制（没动，先记账）

1. **K 折会把 `best.pt` 覆盖成最后一折的**：`_train_kfold()` 逐折调
   `self.train()`，每折都往同一个 `models/detection/` 写，最后留下的是
   最后一折的权重，而不是"平均 mAP 最好"的那折。当前没人用 K 折；要用之前先改这里。
2. **数据量**：28 张 / 300 个框 / 15 类，`C`、`H`、`N` 各只有 5 个实例。
   2 epoch 的 mAP50 是 0.0012（等于没学到），这是数据量问题不是代码问题。
   建议：要么几十张起步的单类"字符"，要么每类补到 100+ 实例。
3. `models/detection/train/weights/` 与 `models/detection/best.pt` 是两份拷贝，
   每次训练多占 ~13 MB。不影响功能，清理策略以后再说。
