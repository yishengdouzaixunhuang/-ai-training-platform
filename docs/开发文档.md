## 2. 数据约定（改代码前必须知道）

- 一个工程 = `<workspace>/<工程名>/`，含 `project.json` / `images/` / `annotations/` / `models/` / `outputs/`。
- 多视图命名：`<组名>_te_0/_te_1/_te_2`（漫反射 / 形状图1 / 形状图2），**三图像素对齐**。
- **标注只标 `te_0`，三视图共用一张掩膜** `annotations/<组名>_te_0_mask.png`。
- `images/<base>.json` 是**标注真源**，掩膜 PNG 只是派生产物（画布 load 时按需回写）。
- 掩膜像素值 = `project.json` 里 `classes` 的**下标**；`255 = __ignore__`。
  ⚠️ **类别顺序就是掩膜语义**：一旦工程已有类别，`merge_classes` 只追加不重排。
- 训练/评估切分：`train_test_split.json`，多视图工程的键是 `<组名>_te_0`。

## 3. 加一个新工具/任务类型的步骤

1. `task_map`（`_open_project_by_name`）里加中英文 task_type 映射；
2. 训练器：`training/` 下按现有 Trainer 的接口实现（`train()` / `cleanup()`）；
3. 推理：优先复用 `inference/predictor.py`；有后处理就加一个 `flow/nodes/xxx.py` 节点并注册；
4. 右侧面板：在对应模块页里加一个**区块**（`_make_section_box(title, [控件...])`）；
5. 工程模板：`core/project_manager.create_project(...)` 里写 `task_type` / `in_channels` / `views`；
6. 补一条 `_set_task()` 分支，并把子页 `currentChanged` 接上（内容高度靠 `ShrinkStack` 自适应）。

## 5. 踩过的坑（改代码前扫一眼，能省几小时）

1. **import 顺序**：`import torch` 必须在 PyQt5 之前，否则 `WinError 1114 c10.dll`。
2. **PyQt5 槽函数里未捕获异常 = 原生 abort（0xC0000409）**，stdout 还会丢；调试用 `python -u`，
   崩溃用 `python -X faulthandler`（能精确定位到 C++ 调用那一行）。
3. **函数中间插 `def`**：语法合法、`py_compile` 通过，但会把后半段变成该方法的不可达函数体 →
   外层 `addWidget(None)` → 0xC0000005。新方法一律加在函数**之后**。
   （自检脚本：AST 查"函数体内直接嵌套 def"和"return 之后还有语句"。）
4. **`QStackedWidget.sizeHint()` 是所有子页的最大值**（实测训练栈 991px vs 当前页 239px）；
   要按当前页算高度必须取 `currentWidget()`（已封装成 `ShrinkStack`）。
5. **细纹理叠加层在缩小视图里必然欠采样**：相位一变就整片消失（窗口2 曾因此"不显示 ignore"）。
   可靠做法 = 平铺半透明底 + 纹理只负责质感，且颜色要靠**色相**与灰阶底图区分。
6. **多视图工程**：`is_multiview_project` 的兜底必须是"单视图"，不能默认三视图。
7. **改过用户工程里的配置文件**（如 `inference_params.json`），测完必须还原或删除。
8. 离屏测试里 `width()/height()` 可能返回**挂起的旧尺寸**，而 `grab()` 会先冲掉挂起 resize —— 
   先 `grab()` 一次再测量，否则量出来的"偏差"是量具的。

## 6. 评估口径

```powershell
# tile 级（扫 最小面积 × 概率阈值），看尺寸分层漏检
python -m tools.eval_farasis --project <工程> --ckpt <模型.pth> --split val --tta --median 3

# 电芯级（整图滑窗拼接后逐缺陷匹配，产线口径）
python -m tools.infer_cell_farasis --project <工程> --ckpt <模型.pth> --src <LabelMe导出根目录> --limit 40
```
